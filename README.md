# Operación KPC — Sesión 09

Actividad asincrónica del curso Principios de Programación en Bioinformática (1ABL0053, UPC.
Scripts en Bash para el análisis inicial de un brote hospitalario de *Klebsiella pneumoniae* productora de carbapenemasa KPC.

## Scripts
1. `informe_sistema.sh` --> Muestra usuario, fecha, directorio actual, uso de disco y lista de archivos.
2. `organizador_datos.sh` --> Crea la estructura `operacion_KPC/` con sus subdirectorios y archivos de ejemplo.
